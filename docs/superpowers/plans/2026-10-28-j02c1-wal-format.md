# J02-C1 — Format et lecteur du journal : plan d'implémentation

> **Pour les agents :** sous-compétence requise : superpowers:executing-plans, tâche par tâche.
>
> **Pas d'étape de commit** : le responsable commite sur une branche `j02c1-wal-format` et ouvre une demande de fusion. Le compte rendu donne les commandes git **et le contenu du formulaire de demande de fusion**.

**Objectif :** encoder et relire les fichiers de journal au format FORMATS §2, sans aucune E/S.
- `FileReader` lit les octets d'un fichier entier et distingue une fin de journal d'une corruption, selon la règle de la zone déchirée bornée.
- `Reassembler` recolle les fragments de 1 Mio d'un fichier au suivant.

**Architecture :** la crate `ndaal-wal` contient des fonctions et des types purs. L'écrivain et les fichiers viendront avec C2.

**Pile :**
- `crc32c` : nouvelle dépendance, nommée par FORMATS §1. Version courante à l'exécution, consignée dans le registre de travail ; `cargo deny` doit l'accepter.
- `thiserror`, `ndaal-common` (`ids`, `bytes`), `proptest`, `criterion`.

**Spécification :** [docs/superpowers/specs/2026-10-28-j02c1-wal-format-design.md](../specs/2026-10-28-j02c1-wal-format-design.md), validée le 2026-10-28. En cas de doute, elle fait foi.

## Contraintes globales

- **Valeurs fixées :**
  - fichiers : magic `NDLWAL01` ; format `1` ; en-tête de 4 096 octets, CRC des octets 0 à 4091 placée aux octets 4092 à 4095 ;
  - trames : en-tête de 40 octets, petit-boutiste, champs dans l'ordre de FORMATS §2.3 ;
  - `MAX_FRAGMENT` = 1 048 576 octets ; `MAX_FLUSH` = 2 097 152 octets ;
  - masque de CRC : `((crc >> 15) | (crc << 17)).wrapping_add(0xa282_ead8)`.
- **Drapeaux d'une trame :**
  - bit 0 : compressé ; bit 1 : chiffré ; ces deux bits donnent `Unsupported` ;
  - bit 2 : dernier fragment ; bit 3 : premier fragment ;
  - bits 4 à 7 : réservés, ils doivent valoir zéro.
- **Drapeaux de l'en-tête de fichier :** bit 0 : chiffré (`Unsupported`) ; bit 1 : recyclé.
- **Code :** aucune E/S, aucune horloge (ADR-017) ; `#![forbid(unsafe_code)]` suffit à C1 ; aucune `panic!` sur des octets lus ; erreurs `thiserror`.
- **Lisibilité :** fichiers de 400 lignes au plus ; ASCII seulement dans les `.rs` ; test d'abord, et une mutation quand un test passe du premier coup.

## Points à surveiller en revue

1. **Une longueur absurde** (`len` > `MAX_FRAGMENT`, ou trame qui dépasse le fichier) est une trame invalide, jamais une allocation ni une panique. Testé à la tâche 3.
2. **Un fichier plus court que 4 096 octets**, ou vide, donne une erreur d'en-tête, sans panique. Testé à la tâche 2.
3. **Des zéros** après la dernière trame (fichier préalloué) donnent `End` à la bonne position, sans balayage coûteux : le type 0 est rejeté avant le calcul de CRC. Testé à la tâche 3.
4. **Une trame d'une autre époque** (fichier recyclé) au milieu de zéros ne déclenche pas `Corrupt`. Testé à la tâche 3.
5. **Un premier fragment au milieu d'un enregistrement en cours**, ou un fragment suivant sans premier, donne une erreur de recollage, jamais un enregistrement collé de travers. Testé à la tâche 4.

- `pub enum WalError` avec les variantes :

### Tâche 2 : trames et encodage

**Fichiers :** créer `crates/ndaal-wal/src/record.rs` et `crates/ndaal-wal/tests/record.rs`.

**Interfaces (produit) :**
- `pub enum RecordType`, avec les codes de FORMATS §2.4 :
  - `KvEffects`, `VecEffects`, `ObjEffects`, `Tx` ;
  - `CheckpointBegin`, `CheckpointEnd`, `Schema`, `Split`, `Merge` ;
  - `RaftMembership`, `RaftBlank`, `ExpireDel`, `GcMark`, `Padding` ;
  - `pub fn code(self) -> u8` et `pub fn from_code(u8) -> Option<Self>`.
- `pub struct Record<'a> { pub kind: RecordType, pub partition: PartitionId, pub lsn: Lsn, pub term: u64, pub timestamp: u64, pub payload: Cow<'a, [u8]> }`.
- `pub const FRAME_HEADER_LEN: usize = 40`, `pub const MAX_FRAGMENT: usize = 1 << 20` et `pub const MAX_FLUSH: usize = 2 << 20`.
- `pub fn encode(record: &Record<'_>, epoch: u64, out: &mut Vec<u8>)` : une trame si `payload.len() <= MAX_FRAGMENT`, sinon des fragments consécutifs (le premier porte le bit 3, le dernier le bit 2, une trame entière porte les deux). Une charge utile vide donne une trame de longueur 0.
- `pub struct Frame<'a> { pub kind, pub partition, pub lsn, pub term, pub timestamp, pub first: bool, pub last: bool, pub payload: &'a [u8] }` et `pub fn encoded_len(payload_len: usize) -> usize`.

- [ ] **Tests d'abord** :
  - `small_record_is_one_frame` : longueur = 40 + charge utile, bits « premier » et « dernier » tous deux mis ;
  - `fragmentation_boundaries` : charges utiles de `MAX_FRAGMENT` (1 trame), `MAX_FRAGMENT + 1` (2 trames) et `3 * MAX_FRAGMENT` (3 trames) ; chaque fragment fait au plus `MAX_FRAGMENT` octets et `encoded_len` correspond ;
  - `epoch_low_bits_in_frame` : époque `0x1_0005` → champ de 16 bits `0x0005` ;
  - `codes_round_trip` : chaque `RecordType` passe par `code` puis `from_code`, et `from_code(0)` = `None`.
- [ ] Lancer `cargo test -p ndaal-wal --test record` : échec, puis réussite.

### Tâche 3 : `FileReader` (fin, corruption, zone déchirée)

**Fichiers :** créer `crates/ndaal-wal/src/reader.rs` et `crates/ndaal-wal/tests/reader.rs`.

**Interfaces :**
- Consomme : `FileHeader::decode`, `masked_crc`, `RecordType::from_code`, `Frame`, les constantes et `encode` (dans les tests).
- Produit :
  - `pub struct FileReader<'a>` avec `pub fn new(file: &'a [u8]) -> Result<FileReader<'a>, WalError>` et `pub fn header(&self) -> &FileHeader` ;
  - `pub fn next(&mut self) -> Result<Step<'a>, WalError>` ;
  - `pub enum Step<'a> { Frame(Frame<'a>), End { valid_len: u64 }, Corrupt { offset: u64 } }`. Une fois `End` ou `Corrupt` rendu, chaque appel suivant rend la même valeur.
- Trames `PADDING` sautées. Une trame valide qui porte le bit « compressé » ou « chiffré » donne `Err(Unsupported)`.
- **Règle de fin** (spec §4.3) : à la première trame invalide, à l'octet `o`, chercher une trame valide entre `o + MAX_FLUSH` et la fin du fichier ; `Corrupt { offset: o }` si on en trouve une, `End { valid_len: o }` sinon. Ordre des tests de validité : place restante, `len`, époque, type, drapeaux, puis CRC.

- [ ] **Tests d'abord**, sur des fichiers construits par `FileHeader::encode` puis `encode` :
  - `reads_back_what_was_written` ;
  - `zeros_after_the_log_are_the_end` : un fichier de 8 Mio rempli de zéros après 3 trames donne `End` juste après la troisième ;
  - `old_epoch_is_the_end` : les trames d'une autre époque derrière les trames valides donnent `End` ;
  - `torn_zone_is_the_end` : trame abîmée, puis trames valides à moins de `MAX_FLUSH` → `End` ;
  - `corruption_beyond_the_torn_zone` : trame abîmée, puis trames valides à plus de `MAX_FLUSH` → `Corrupt` avec le bon offset ;
  - `absurd_length_is_invalid` : `len` = `u32::MAX`, et une trame qui dépasse le fichier ;
  - `every_flipped_bit_is_caught` (T02.07) : un fichier de 3 petites trames ; pour chaque bit de chaque octet après l'en-tête, aucune `Frame` altérée n'est rendue ;
  - `every_truncation_is_a_prefix` (T02.10) : pour chaque longueur de coupe, on obtient les trames entières qui tiennent, puis `End` ;
  - `compressed_flag_is_unsupported`.
- [ ] Lancer `cargo test -p ndaal-wal --test reader` : échec, puis réussite.

### Tâche 4 : `Reassembler`

**Fichiers :** créer `crates/ndaal-wal/src/reassemble.rs` et `crates/ndaal-wal/tests/reassemble.rs`.

**Interfaces :**
- Produit :
  - `pub struct Reassembler`, avec `Default` ;
  - `pub fn push<'a>(&mut self, frame: Frame<'a>) -> Result<Option<Record<'a>>, WalError>` : rend `Some` pour une trame entière (charge utile empruntée) ou pour le dernier fragment (charge utile copiée) ;
  - `pub fn pending(&self) -> bool` : un enregistrement commencé et non fini ;
  - `pub enum FragmentError { Missing, Unexpected, Mismatch }`.
- **Règles :**
  - un fragment sans premier, ou un premier alors qu'un enregistrement est en cours, donne `Unexpected` ;
  - un fragment dont la partition, le LSN, le type, le terme ou l'horodatage diffère donne `Mismatch` ;
  - le recollage continue d'un `FileReader` au suivant (l'état est gardé) ;
  - une fin de journal avec `pending()` vrai donne un enregistrement incomplet, que le consommateur (C2) écarte.

- [ ] **Tests d'abord :**
  - `whole_frame_is_borrowed` (`Cow::Borrowed`) ;
  - `fragments_across_two_files` : un enregistrement de 2,5 Mio coupé entre deux fichiers est rendu intact ;
  - `stray_and_duplicate_fragments` ;
  - `mismatched_fragment` ;
  - `round_trip` (`proptest`) : des enregistrements quelconques (types, charges utiles de 0 octet à 3 Mio, époques) répartis sur plusieurs fichiers, relus par `FileReader` puis `Reassembler`, sont égaux aux enregistrements écrits.
- [ ] Lancer `cargo test -p ndaal-wal` : réussite.
